## 🤖 BOT FURIA | Telegram

Este projeto foi desenvolvido para a FURIA Esports, com o objetivo de aproximar os fãs do time através de um bot no Telegram, fornecendo informações atualizadas sobre jogos, campeonatos, lineups e muito mais.

## 📌 O que é o Bot da FURIA?

O BOT FURIA é um assistente virtual criado para interagir com os torcedores da FURIA. Ele fornece:

Detalhes do próximo jogo

Lineup atual

Histórico de partidas

Links das redes sociais

Acesso a grupos de fãs

... tudo isso via comandos simples no Telegram.

## 👤 Para os torcedores

Ao iniciar o bot com /start, você receberá um menu de opções para explorar:

Lista de Comandos:

Comando

Função

/start

Informações iniciais sobre o bot

/comandos ou /help

Lista de comandos disponíveis

/lineup

Mostra a escalação atual da equipe

/proximojogo

Informações sobre o próximo jogo da FURIA

/proximocamp

Detalhes do próximo campeonato

/ultimosresultados

Resultados das últimas 5 partidas

/historico

Histórico geral da equipe

/paginas

Links das redes sociais e loja

/grupo

Acesso à Fanzone no Telegram

## 🛠️ Tecnologias Utilizadas

Python 3.11+

Selenium + WebDriver (Chrome) para scraping em tempo real

Python-Telegram-Bot para integração com o Telegram

Liquipedia como fonte principal de dados

## 🚀 Como rodar o projeto localmente

Requisitos:

Python instalado

Chrome instalado

Passos:

# 1. Clone este repositório
$ git clone https://github.com/hugopleme/ChatBOT_Furia

# 2. Acesse a pasta do projeto
$ cd ChatBOT_Furia

# 3. Instale as dependências
$ pip install -r requirements.txt

# 4. Execute o bot
$ python main.py
